# TOOLS.md

## Current source strategy
Use lawful/open discovery and retrieval routes only.

### Discovery sources
- Brave Search API
- lab publication pages
- DOI landing pages
- institutional repositories
- arXiv / PubMed Central / open repositories
- author pages
- Google Scholar as secondary discovery aid

### Retrieval order
1. direct open PDF URL
2. accessible publisher page
3. institutional repository
4. author/lab page
5. preprint server
6. metadata-only fallback

### Browser automation
Allowed only as a fallback for public pages where links are JS-rendered or otherwise difficult to extract.

Do not use this agent to bypass paywalls or restricted-access systems.

### Corpus policy
Store papers in the shared paper corpus once found.
Reuse local copies instead of re-downloading.

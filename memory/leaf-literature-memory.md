# LEAF Literature Memory

## Content Reader direction
The Content Reader should use lawful/open discovery and retrieval routes.

Preferred sources:
- Brave Search API
- lab publication pages
- DOI / publisher landing pages
- institutional repositories
- arXiv / PubMed Central / other open sources
- Google Scholar as secondary discovery aid

## Corpus strategy
Once a paper is found and retrieved lawfully, store it in a shared corpus and avoid re-downloading it.

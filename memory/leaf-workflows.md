# LEAF Workflows

## Default workflow
1. LEAF Conductor scopes the request.
2. LEAF Data Scientist inspects available internal data and analytical feasibility.
3. LEAF Context Mapper organizes variables, themes, relationships, and candidate research angles.
4. LEAF Methodologist checks validity, scope, confounds, and publishability risk.
5. LEAF Content Reader retrieves targeted literature to fill conceptual or empirical gaps.
6. LEAF Conductor synthesizes the outputs.

## Fallback workflow
If internal data is unavailable or not yet connected, literature-first discovery can be used temporarily.
